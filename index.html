What exactly does the counter measure?

Each button schedules one requestAnimationFrame. The counter observes the application NgZone’s onMicrotaskEmpty event. A nested runOutsideAngular can activate the parent while registering the frame and again when its callback runs.

Buttons and result updates run outside Angular so the demo controls do not cause the events being measured. These are zone events, not ApplicationRef tick counts or timings. No popover is rendered and no private Angular fields are read.
